# Amazon Sales Dashboard Using Power BI

## Project Overview

This project presents an interactive Amazon Sales Dashboard created using Power BI. The dashboard analyzes sales performance, product categories, regional sales, customers, and payment methods.

## Project Objectives

- Analyze overall sales performance
- Identify top-performing product categories and products
- Understand regional sales patterns
- Analyze customer and order information
- Compare different payment methods
- Present insights through interactive Power BI visualizations

## Dataset

The dataset contains Amazon-style sales transaction data covering the period from January 2023 to December 2024.

Key fields include:
- Order ID
- Order Date
- Category
- Product Name
- Quantity
- Price
- Sales
- Region
- Customer Name
- Payment Method

## Tools Used

- Power BI
- Power Query
- DAX
- Microsoft Excel / CSV

Dashboard Pages

 1. Sales Overview
Provides an overview of total sales, orders, average order value, units sold, monthly sales trends, payment methods, and regional sales.

 2. Product & Category Analysis
Analyzes sales by category, top products, and quantity sold across categories.

 3. Regional & Customer Analysis
Shows customer information, regional orders, regional sales share, and payment method usage.
